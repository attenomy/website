# ⚫ Attenomy - Modern Company Website

A cutting-edge website built with modern technologies to deliver exceptional user experiences.

## 🚀 Features

- **Blazing Fast Performance** - Optimized for speed and efficiency
- **Responsive Design** - Flawless experience across all devices
- **Modern UI/UX** - Clean, intuitive interface with smooth animations
- **Theme Support** - Automatic dark/light mode based on user preference
- **Accessibility First** - Built with WCAG guidelines in mind

## 🛠 Tech Stack

### Frontend
- **React 18** - Latest React features and concurrent rendering
- **Next.js 14** - App router, server components, and optimized performance
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first styling with custom design system
- **Framer Motion** - Smooth animations and transitions

### Backend & Infrastructure
- **Vercel/Netlify** - Deployment platform
